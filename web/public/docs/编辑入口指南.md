# 凿星图 · 编辑入口指南

主页唯一源文件为 `web/index.html`；`caelum.html` 是历史副本。不要执行 `cp caelum.html web/index.html`，否则会覆盖修复与新入口。完整流程见《更新指南》。

| 想改什么 | 文件与位置 |
| --- | --- |
| 姓名 / 字 / 引言 / 滚动提示 | `web/public/data/text.json` 的 intro，保留 zh/en |
| 星图 / 星域 / 研究 / 文字的一句话 | 同文件的 taglines |
| 星愿 / 跋文 / 手册链接 | 同文件的 vision 与 coda |
| 研究方向 / 论文 / 学术履历链接 | `web/index.html` 的 sec-frontier 章节，按事实维护 |
| 文章、随笔和日记列表 | `web/public/data/articles.json`，保留分类、日期和有效 URL |
| 四域目录与学习页 | `web/public/tree.json` 的 domains 数组 |
| 星图书目与坐标 | `web/public/data/graph.json`，批量生成流程见《更新指南》 |
| 网页添加的条目 | `web/public/data/inbox.json` |
| 房间公开内容 | `web/public/data/room.json`，书籍/文章也读取现有数据 |
| 房间家具、场景与交互 | `web/room/scene.svg`、room.css、room.js 与 `web/room.html` |
| 私人标记和笔记 | 在网页中操作；只存本机，不改公开 JSON |

## 四域结构

最外层结构必须保留：

```json
{
  "domains": [
    { "id": "formal", "zh": "形式科学", "en": "Formal Sciences", "children": [] }
  ]
}
```

有 children 的节点为目录，无 children 的节点为叶子。可为叶子补充 desc、concepts、questions、books、links。id 应稳定且唯一，避免破坏浏览器按 id 保存的学习标记。字段值不应混入脚本或 javascript: URL。

## 最小验证流程

从仓库根执行：

```sh
npm --prefix web run build
npm --prefix web test
npm --prefix web run preview -- --host 127.0.0.1
git diff --check
```

首次先执行 `npm --prefix web ci`。打开 `http://127.0.0.1:4173/web/` 及 `/web/room.html`，检查改动后的内容与交互，再审查暂存范围并提交。main 的唯一 Pages 流程部署公开产物；本地预览成功不能代替线上确认。

分享主站用 [https://nyxbyb.github.io/web/](https://nyxbyb.github.io/web/)，房间用 [https://nyxbyb.github.io/web/room.html](https://nyxbyb.github.io/web/room.html)。旧 `/web/index.html` 保留。

## 公开边界

所有 `web/public/` 文件都会公开。token 仅用于本次编辑请求，不保存于浏览器持久存储；私人笔记/截图不要填入公开投稿。文案须检查中英文。部署不会跨设备同步本机标记与笔记，重要记录另行备份。
