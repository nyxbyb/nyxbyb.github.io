# 迟庭 · Caelum 住宅设计简报

更新：2026-10-21 · REV.03 · 茶室与园居深化

## 本轮协调成果

本轮重点是起居茶室与周边园居。W03的150mm低窗台、固定窗V06、推拉门D09、实墙柱和檐口在室内外共同定位；茶水柜、茶席、听音、灯光插座、清洗和收纳进入模型。原15.54㎡预留房成为画室；影音、健身与泳池作为单独扩展，主宅200㎡口径不变。详细来源与使用说明见[园居与茶室深化](./园居与茶室深化.md)。

住宅命名为 **迟庭 · CHITING / A HOUSE WITH TIME**。从独立氛围图转为一份可持续深化的全屋设计资料：生活简报、同模型平面与视点、动线、逐室立面、纵剖、门窗表、家具尺寸表、材料、照明设备策略与交付记录。专业体系依据见 [住宅设计交付体系](./住宅设计交付体系.md)，与公开文章及阅读记录的联系见 [居住者与生活场景](./居住者与生活场景.md)。

几何唯一来源是 `web/room/spatial-model.js`：9个浏览区域、12个物理空间、17面墙、22个门窗/开敞通道、67件家具与台面附属物、10个固定视点（含茶席特写）、4条主宅生活路线。图纸、清单、几何视图与可打印设计册读取同一份米制资料，门D、窗V、通道P、家具F、视点C、路线R有稳定编号。研究室内高度为2.70m，九个主摄影机高1.50m，茶席C-tea为1.25m坐姿视点、75°视场；摄影图示门扇关闭，平面显示开启范围。

本轮修复了庭院只有窗没有入口、厨房入口被柜体占据、餐椅阻断西侧路线、客床展开后通窗受阻和部分门扇扫掠碰撞等问题。主宅路线以0.75–0.9m的概念净带逐段核对，茶柜前的0.5m局部服务带单独标注，平开门按完整90°范围检查家具与相机占位；此检查不等同于某项无障碍或施工验收认证。

网页固定视点可在材质影像与模型几何视图间切换；门窗与家具以同模型图纸/清单为位置依据。生成影像不能代替毫米级测绘、具体产品尺寸、机电和构造深化。此前REV.01图片保留为历史素材，不再作为当前方案的空间依据。

## 本次设计范围

采用用户确认的 **180–220㎡ 独栋住宅与庭院**，以约 **200㎡ 概念建筑面积**作为本版工作模型。日式现代、自然木质、温暖简洁是已确认的方向；网站采用二维建筑图版、固定视点室内图与同模型几何图，作为未来建房、装修时持续积累的参考。

生活假设是现在一个人居住，兼顾今后共同生活、朋友或家人短住。房间配置依据阅读、研究、日常生活与未来变化确定，不由年龄或性别套用固定模板。本版替代早期尚未确认的 120–150㎡ 假设。

这是一份原创概念研究，官方案例提供可核对的设计依据，未获得相关设计师参与或背书。平面、尺寸、面积与图像均非测绘或施工文件；真实项目需依据基地、预算、气候、结构、设备及当地要求继续设计。

## 需要多少房间

建议先确定 **四个可以独立关门的房间**：主卧、独立书房、客房兼多用房、画室与可变工作间。它们不等于四间卧室。

- 主卧用于睡眠与日常衣物，保持安静。
- 独立书房对应长期阅读、写作和计算机研究，关闭房门后能与公共活动分开。
- 客房兼多用房平时可用于运动、手工、临时项目；有人留宿时恢复为客房。
- 画室用于纸面、素描与水性创作，配置独立洗笔、平面收纳与晾画位置；保留可移动家具，未来仍可变化。

起居、茶与日常藏书合在公共区，餐厨相邻。卫生、洗衣、清洁工具、行李和设备各有位置，避免为独立“主题房”持续增加面积。

以下为统一的程序面积目标，不是从渲染图倒推的测量结果。区域几何与家具控制占位已统一，墙厚、完成面净尺度与选定产品须继续深化。

| 客房兼多用房 | 13.86㎡ | 客床与活动空间可以切换，避免家具永久挤满。 |
| 画室与可变工作间 | 15.54㎡ | 北窗、画架、工作台、平面画材收纳与独立洗笔位置。 |
| 两卫与小前室 | 11.76㎡ | 由公共交通区到达，干湿与清洁收纳继续细化。 |
| 玄关、洗衣与储物 | 12㎡ | 换鞋、行李、清洁、洗晒及设备检修位置继续细化。 |

| **净功能合计** | **166㎡** | 与二维示意的区域几何相加一致，不含墙体与机电等预留。 |
| 墙体、结构、机电及后续设计预留 | 34㎡ | 为面积口径、围护和设备深化保留余量。 |
| **概念建筑面积目标** | **200㎡** | 属本版研究总量，不是报建测算值。 |

二维示意采用 **14 × 14m 的净空间研究外框，扣除西南侧 6 × 5m 庭院**，所得 166㎡由上表区域组成。庭院约 **30㎡**，作为独立的室外研究对象，不计入室内净功能合计。外框是程序图的概念尺寸，不是含墙厚的建筑外边线；34㎡也仅为预留，尚未绘制成最终构造。檐廊、雨棚、庭院等在真实项目中的面积认定，需按所在地与最终形式重新计算。

若最终控制在 180㎡，优先压缩公共区、画室与交通，而非取消储物、洗衣或让书房侵入卧室；若扩大到 220㎡，优先改善通行、设备与室内外过渡，不急于继续增加房间数量。具体减加量应在真实平面上重新核算。

## 空间关系

采用紧凑的 L 形两翼围合半开放庭院。公共区朝向庭院；北侧为主卧、两卫、客房与画室，独立书房位于南端、紧邻玄关。庭院也可以随基地改为侧院或后院；L 形是本次设计假设，不是与地点无关的唯一答案。

- 日常公共路径：玄关 → 餐厨 → 起居与茶 → 庭院。
- 安静路径：公共区 → 1.4m回廊 → 主卧、客房、画室；书房由玄关的D02独立进入。
- 客人去客卫不需要穿越主卧。
- 餐厨操作面沿北、东两面，家务设备在东南玄关，两卫在北部中央。它们并非已合并成一个管井；冷热水距离、排水坡度、通风与检修应在真实项目中协调。
- 主卧避开玄关正视线与厨房、洗衣设备的直接干扰。
- 当前内廊交通占 19.6㎡，是清楚列出的空间成本；艺术展示与阅读停留是待研究的用途，不能把这部分面积直接称为卧室或储物面积。后续真实平面应检验是否能够缩短动线。
- 研究连续、少高差的通行，给门口、床侧、卫生间与家具周边保留调整空间；实际尺寸由真实使用者与后续设计确定，不据此宣称满足某项无障碍规范。

## 材料与细部方向

主背景采用低饱和的暖白、浅木与米灰，少量深色金属或石材用于必要细部。木饰面集中于柜体、家具及局部天花，不要求整屋木包覆。窗边亚麻、可拆洗织物与局部编织材料提供触感；选择易替换的部件，让今后的修补成为设计的一部分。

照明分为环境、阅读和操作三层。氛围图可以表达暖光，但书桌、厨房、清洁和照护时的亮度需求另行研究。窗、庭院、格栅与屋檐需要共同讨论；大玻璃、纤细框体或过深阴影都不应只因画面漂亮便直接落地。

## 下一轮真实项目需要的信息

落地前优先补齐基地城市与朝向、地块或现有户型尺寸、周边视线与噪声、预算范围、常住与短住人数、烹饪习惯、藏书规模、设备需求，以及是否需要适应行动能力变化。信息明确后，再把本册中的空间意向转为可校核的平面、立面、材料样板与专业设计文件。

网页中的平面、立面、剖面、几何视图和表格共用同一模型。固定视点材质影像用于选择光、表面与家具语言，结构位置可用几何图与门窗编号核对。真实项目仍需选址、测绘、预算、结构机电、产品选型与构造图纸。
