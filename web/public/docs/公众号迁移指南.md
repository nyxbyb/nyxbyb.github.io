# 把公众号（坚心Nyx）的文章搬进凿星图

> 公众号没有开放 API，也没有官方导出，所以只能是你手动复制 + 我自动结构化。
> 但**你不用排版、不用写格式**——粘贴纯文本即可，我处理剩下的一切。

## 每一步要做什么

### 1. 打开一篇文章的全文

在手机上：
1. 打开 **微信** → 进入你自己的公众号
2. 打开某篇文章 → 点右上角 **···** → **复制链接**（可选）
3. 在文章页 **长按选中全部正文** → **复制**

在电脑上（更顺手，推荐）：
- 打开公众号后台 **https://mp.weixin.qq.com** → 素材管理 → 图文素材
- 打开一篇文章 → 全选正文 → 复制

### 2. 粘贴进凿星图

把正文 **纯文本** 粘贴到任意文本输入框，发给我（在 Claude 里），或直接存成一个 `.txt`。
一次贴一篇即可，我会：

- 自动套上 front-matter（标题 / 日期 / 类型=article）
- 保存到 `corpus/articles/`（私人目录，不进公开仓库）
- 嵌入语义空间 → 下一版星图上出现它的**三角形**节点

### 3. （批量）

如果你能一次提供 20–50 篇文章的纯文本，我可以写成一条"粘贴即入库"的脚本，让你之后自己批量灌。但**初始阶段，一篇一篇来最快**。

## 为什么不是全自动抓取

微信公众号的反爬与登录墙使得全自动抓取极不可靠且可能违规。
这条路（手动复制 + 自动结构化）是最诚实、最私密、最稳定的——你的文章本来就是你的，复制它们不违法。

## 你只需要记住一句话

> **复制正文 → 粘贴 → 发我。剩下我来。**
