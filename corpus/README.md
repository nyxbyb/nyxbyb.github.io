# 语料库 · Caelum 的"原料仓"

这里是整个项目唯一需要你手工维护的地方。三类精神印记各一个文件夹，
每个条目一个 Markdown 文件。**你只需要往这里放文件，剩下的嵌入、降维、
成图、推荐全部交给流水线。**

```
corpus/
├── books/      书（经典底图 + 你读过的）   —— 一个文件一本书
├── articles/   你的公众号文章 / 随笔 / 书评  —— 一个文件一篇
└── papers/     你发表的论文                —— 一个文件一篇
```

## 文件 = front-matter（元数据） + 正文（你的文字）

嵌入时会把【标题 + 作者 + 简介 + 你的正文】一起编码，所以**正文里你写的
书评/笔记/摘要越真诚，节点就越代表"你与它的关系"**，而不只是冷冰冰的元数据。

各文件夹里的 `_template.md` 是模板，复制改字段即可。`_example_*.md` 是
填好的示例。以下划线 `_` 开头的文件会被流水线忽略，可放心保留。

## 三类条目的关键区别

| 字段 | books | articles | papers |
|---|---|---|---|
| `type` | `book` | `article` | `paper` |
| `status` | `read`/`unread`/`reading` | 恒为 `read`（你写的） | 恒为 `read` |
| `rating` | 已读才填 1–5 | — | — |
| `link` | 豆瓣/购书链接 | **公众号原文链接** | DOI/会议页 |

> 命名建议：`书名.md`、`YYYY-MM-标题.md`、`年份-论文短名.md`，避免特殊字符。
