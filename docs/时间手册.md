## 第三章 已实现（截至 2026-09-06）

### 3.1 已上线：星图在 nyxbyb.github.io

整个网站在 **2026-09-06** 正式发布于 **https://nyxbyb.github.io**（GitHub 用户名站点，仓库 `nyxbyb.github.io`）。

一条完整链路已跑通：

```
豆瓣书目爬取 → 文本嵌入 → TSNE 降维到 3D → 前端渲染 → GitHub Actions 部署
```

### 3.2 具体构件

- **爬坑器** `scripts/crawl_all.py` —— 抓豆瓣 Top250（10 页）+ 14 个分类榜，去重得 **1028 本**中文世界主流经典，落 `corpus/books_raw.json`。
- **嵌入器** `scripts/embed_map.py` —— `fastembed` 中文模型（512 维），TSNE **三维**输出 → `web/public/data/graph.json`。
- **星图前端** `web/`（Vite + 原生 Canvas，单页 `index.html`）——
  - **三态标记**：喜爱 / 已读 / 未读（localStorage 持久化，留在浏览器本地）
  - **3D 可旋转星图**：拖拽旋转、悬停书名、点击标记、X/Y/Z 三轴 + 每轴已读亮度分布条
  - 拖拽平移 / 滚轮缩放交互
  - 五屏叙事结构：序 / 星图 / 星域 / 拓星 / 跋
- **双语**：全站中英切换（右上角 toggle，localStorage 记忆）
- **拓星**：填入 Google Scholar 9 篇论文
- **部署** `.github/workflows/deploy.yml` —— push 到 main 自动构建 + 发布到 GitHub Pages。

### 3.3 隐私体系的既定边界

- 公开仓库只含：代码、脚本、星图底图（书名/作者/评分/坐标 —— 无个人信息）。
- **私人语料目录已 gitignore**：`corpus/books|articles|papers/` 下的内容不进公开仓库。
- 你的三态光斑存在 localStorage —— **只在你的浏览器里，永不外传**。公开站显示的是灰寂的星野。

## 第五·五章 2026-09-06 晚 · 关键设计决策（追加）

这几条是当日对话中确定的，对未来走向有约束力，特此记录：

- **公开边界（定）**：微信读书、公众号**已发表内容可公开**；私人笔记（叶子书评、读过标记）存 localStorage，采用"可选公开"策略，不默认上公网。
- **星域叶子页（定）**：每个叶子是**独立全屏页面**，采用**权威条目式**（SEP/维基百科式）：定义 / 核心概念 / 关键问题 / 经典书目 / 我的笔记 / 延伸链接。tree.json 的叶子带 desc/concepts/questions/books/links 字段；已给 6 个示范叶子注入内容。
- **星图坐标轴（定）**：现存的 X/Y/Z 轴**无语义**（书缺乏标签），将改用**嵌入聚类**给三轴贴语义标签（如"文学-科学""理论-应用"），使"哪轴亮多"有意义。计划中。
- **更新迭代性（定）**：`scripts/update.sh` 一键更新；`docs/更新指南.md` 分场景（新文章/新书/改文字）说明两步流程；公众号抓取结果备份在 `data/公众号/_backup/` 防重复爬。
- **给大模型的阅读材料（定）**：`docs/profile.md` 已含完整 **162 本书 / 59 篇文章 / 9 篇论文** 列表，供任何大模型快速认知"我读过什么、写过什么、研究什么"。
