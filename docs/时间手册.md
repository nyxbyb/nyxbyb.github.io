## 卷三 · 已实现（截至 2026-09-06）

### 已上线：星图在 nyxbyb.github.io

整个网站在 **2026-09-06** 正式发布于 **https://nyxbyb.github.io**（GitHub 用户名站点，仓库 `nyxbyb.github.io`）。

一条完整链路已跑通：

```
豆瓣书目爬取 → 文本嵌入 → TSNE 降维到 2D → Vite+Svelte 前端渲染 → GitHub Actions 部署
```

具体构件（全部在本仓库的 scripts/ 与 web/）：

- **爬坑器** `scripts/crawl_all.py` —— 抓豆瓣 Top250（10 页）+ 14 个分类榜（文学/小说/哲学/历史/科幻/诗歌/心理学/社会学/传记/艺术/思想/随笔/中国文学/外国文学），去重合并后得 **1028 本**中文世界主流经典，落 `corpus/books_raw.json`。
- **嵌入器** `scripts/embed_map.py` —— `fastembed` 加载轻量中文模型（约 100MB，首次下载缓存），每本产出 512 维向量；TSNE 降至 2D → `web/public/data/graph.json`.
- **星图前端** `web/`（Vite + Svelte 5 + 原生 Canvas）——
  - 1028 节点渲染，拖拽平移 / 滚轮缩放
  - 点击节点弹卡片（书名 / 作者 / 豆瓣评分 / 标为已读 / 标为未读）
  - **已读 = 暖色光斑 + 光晕**，未读 = 冷灰；节点间自带轻微区分
  - **精神质心**：按已读节点算加权中心，画一颗星形 marker
  - **localStorage 持久化**：你的已读标记留在浏览器本地，刷新不丢
- **部署** `.github/workflows/deploy.yml` —— push 到 main 自动构建 + 发布到 GitHub Pages（用户站点根路径）。

### 隐私体系的既定边界

- 公开仓库只含：代码、脚本、星图底图（书名/作者/评分/坐标 —— 无个人信息）。
- **私人语料目录已 gitignore**：`corpus/books|articles|papers/` 下的内容（你的真实书评、文章、论文）不进公开仓库。
- 你的"已读光斑"存在 localStorage —— **只在你的浏览器里，永不外传**。公开站显示的是灰寂的星野，你的光只在你心里亮。
- 外发边界：嵌入用本地模型，书目数据不发往任何第三方。若未来换 API 嵌入，需先在此记录该决定。
