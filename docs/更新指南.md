# 凿星图 · 更新指南

> **核心：所有更新只需要两步——「改内容」+「跑一条命令」。**
> 改完跑 `bash scripts/update.sh "说明"`，约 1 分钟后线上更新。

---

## 一、三大更新场景

### 1. 新写了一篇公众号文章

1. 打开 `data/公众号/随笔.md`（或 `日记.md`），**加一行**公众号链接：
   ```
   [mp.weixin.qq.com/s/xxxx](https://mp.weixin.qq.com/s/xxxx)
   ```
2. 抓取标题/简介 + 更新：
   ```bash
   python3 scripts/fetch_wx_meta.py   # 只需要抓取/更新时才要跑
   ```
   > 这步把链接转成 标题/简介 数据。只有第一次或新文章才要跑，可跳过（会有一条无名链接）。
3. 部署：
   ```bash
   bash scripts/update.sh "新增随笔：xxx"
   ```

### 2. 读完了一本新书

1. **微信读书截图**：截一张"读完"记录长图放进 `data/微信读书/`
2. 结构化（OCR 自动提取书名/时长/月份）：
   ```bash
   # 重新对截图 OCR 并解析
   swift /tmp/ocr.swift 你自己的截图.jpg        # 或用已有的 OCR 流程
   python3 scripts/parse_wxr_full.py           # 更新 reading_records_full.json
   ```
   > 实际上最简单：把新截图路径告诉 Claude，或手动把书名加进 `reading_records_full.json`。
3. 重新嵌入并入星图 + 部署：
   ```bash
   bash scripts/update.sh "读完：新书入手"
   ```

### 3. 改了文字（首页名/字、理念句子、拓星论文）

**不用跑任何脚本**，直接改动对应文件后一键部署：
```bash
bash scripts/update.sh "改文字"
```

## 二、内容各自在哪改

| 内容 | 文件 | 位置 |
|---|---|---|
| 首页中文名 | `caelum.html` | 顶部 `.name-cn` |
| 首页英文名 | `caelum.html` | `.name-en` |
| 字与出处 | `caelum.html` | `.name-zi` |
| 引言 | `caelum.html` | `第 1 屏` 注释块 |
| 星域目录树 | `web/public/tree.json` | 加学科/叶子页字段 |
| 叶子页内容 | `web/public/tree.json` | 叶子的 desc/concepts/questions/books/links |
| 拓星研究方向 | `caelum.html` | `第 4 屏` `.frontier-tags` |
| 拓星代表作 | `caelum.html` | `第 4 屏` 每个 `.frontier-item` |
| 随笔/日记 | `data/公众号/*.md` → `articles.json` | 链接 → 抓取 |
| 星图书单 | `corpus/books_raw.json` | 数据库 |
| 理念页句子 | `caelum.html` | `第 5 屏` `.vs-*` |

> 每个 HTML 改动点都有 `✏️ 编辑入口` 注释标注，搜 `✏️` 即可全部定位。

## 三、一键更新脚本做了什么

`bash scripts/update.sh "说明"` 依次：
1. 重新嵌入 + 降维（若有书单/读书记录变化）
2. 同步 `caelum.html → web/index.html`
3. `git add` + `commit "说明"`
4. `git push` → GitHub Actions 自动构建部署

## 四、隐私边界（重要）

- **已发表的内容**（微信读书书名/时长/完成月、公众号文章标题/简介/链接）→ 公开，进公开仓库
- **你的私人笔记**（叶子页的书评/感想、读过标记、掌掌握度）→ 现在存 localStorage（只在你浏览器）；如果你想让它们也上线，需要"导出上传"改造，具体见《空间手册》
- 阅读长截图、微信读书截图 → 留在本地 `data/微信读书/`，**永不进公开仓库**（gitignore 已挡）

## 五、一次完整的新文章流程（例子）

```
微信后台复制链接
      ↓
随笔.md 加一行
      ↓
python3 scripts/fetch_wx_meta.py   # 抓标题简介
bash scripts/update.sh "新增随笔《熵减对话录》"
      ↓
约 1 分钟后 https://nyxbyb.github.io 随笔页出现新篇
```

> 全程 2 分钟，不改 HTML，不动星图代码。
