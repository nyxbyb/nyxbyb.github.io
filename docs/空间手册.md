# 凿星图 · Caelum —— 空间手册

> 本册是本网站的**存在论**——回答"它是什么"。
> 另一册《时间手册》回答"它如何成为"。一本讲空间，一本讲时间；合起来，是一面镜子的一生。

---

## 第一章 缘起：我在问自己什么

这个网站不是读书管理工具。它不是书目、不是简历、不是收藏陈列馆。

它是我为自己建造的**文字存在论博物馆**——一间以文字为存在证明的房间。在里面，我读过的书、我写过的文章、我发表的论文，不是"我的资料"，而是**我的精神存在的地形**。

### 1.1 三个问题

1. **我被什么塑造了？** 我的阅读史在语义空间中呈现怎样的分布？我的精神质心落在哪里？
2. **我的盲区在哪里？** 距离我质心最近、但我尚未读过的书有哪些？那些才是我真正"相见恨晚"的漏网之鱼。
3. **我的输入与输出是否共振？** 我读的书、我写的文章、我发表的论文，在同一个语义空间中是否指向同一个方向？

这三个问题，本质上是同一个问题的三个侧面——**我是谁**。

### 1.2 一座博物馆，为什么要有两幅地图

记录我的足迹，也绘制我的视野。足迹告诉我**我去过哪里**；视野告诉我**我为何那样划分世界**。两者叠起来，才有完整的精神地貌。

## 第二章 公理：这座建筑的承重墙

任何体系都要先声明它赖以成立的假设。凿星图建立在三条公理之上：

### 2.1 公理一 · 存在即文本，文本即坐标

一个人生命中所有以文字为载体的精神印记——读的、写的、造的——都可以被放置在同一个语义空间中。你不先有一份履历；你先有一片文字的地形。一本书从此存在，是因为它被我的目光照亮过。

### 2.2 公理二 · 地图是关系，不是收藏

每个节点不是客观的一本书，而是"我与这本书的关系"。一个节点在空间中的位置，取决于我知道它、感受它、回应它的方式——而非它的图书馆分类。因此，这张图**天生是第一人称的**。同一个马尔克斯，在别人心里是拉美魔幻，在我心里是"孤独如何在家族中遗传"——我们的节点，会有不同的坐标。

### 2.3 公理三 · 自知即看见偏见

认知星图不是客观的学科图，而是我个人的、带着偏爱的理解方式。它不假装中立。看见自己的偏见，就是自知的开端；而凿星图的使命，正是让我**清晰地看见自己的偏见**。

> 这一公理呼应一个判断：这个体系的目的是"准确"，不是"全面"。准确——准确地反映我如何理解世界；而非成为一个通用的知识库。

## 第三章 双地图论

凿星图由两层地图构成，像古星图上叠加的两种线：**星星**（我踩过的地点）与**星座连线**（我为位置赋予的意义）。

### 3.1 第一幅地图：足迹图 —— 位置层

记录我的**足迹**：读过什么、写过什么、发表过什么。

- 书（读过的 / 未读的 / 喜爱的）—— 圆点
- 文章、书评、随笔 —— 三角形
- 论文 —— 方形

节点在语义空间中的坐标，由内容的嵌入向量经降维得到。不同的标记被照成不同的光：喜爱最亮，已读次之，未读保持灰色——**我的光斑**由此浮现。

### 3.2 第二幅地图：认知星图 —— 坐标系层

记录我的**视野**：在我眼中，人类智慧的疆域是如何被划分的。它不是从任何学科目录里抄来的分类，而是我个人理解世界的方式。它不遮挡星星，但赋予每个位置以意义——这就是"底图层"。

### 3.3 精神地貌图

两幅地图叠在一起，就是我的精神地貌图。

## 第四章 认知星图：四域分类树

### 4.1 它是一棵目录树，不是一组标签

认知星图是一个**分类学**（taxonomy），不是一组标签——它是一棵目录树。数、领域、学科、分支逐级展开，像一幅再带层层放大的地图。

```
人类智慧
├── 形式科学           —— 纯粹结构 · 推演与计算
│     ├── 逻辑
│     ├── 数学
│     │     ├── 代数
│     │     ├── 分析
│     │     └── 几何 / 拓扑
│     └── 计算机理论（计算理论 · 信息论）
├── 自然科学           —— 自然如何运行 · 因果律
│     ├── 物理学 │ 化学 │ 生物学 │ 地球科学
├── 人文与社会科学     —— 人类如何构建意义
│     ├── 哲学（形而上学 · 认识论 · 伦理学 · 中国哲学）
│     ├── 心理学 └── 精神分析   ← 我的深入切入口
│     ├── 历史 │ 文学 │ 经济学 │ 政治学 │ 法学（理论）
└── 应用科学与技艺     —— 人如何介入并改造世界
      ├── 工程 │ 医学 │ 农学 │ 商学 │ 法学（实践）
```

上树仅示骨架。这棵树**由我随学习而生长**——目录不是外来的权威，而是我自己绘制的航线图。树的分支可以在学习中增删，就像地图会因新发现而被重新绘制。

### 4.2 四域的认知姿态

这是认知星图最深的秘密：**我在不同领域中，与知识的关系是不同的。**

| 域 | 我的定位 | 认知姿态 |
|---|---|---|
| 形式科学 | 母域 | **专业视角**——我在此有专业的精度与直觉 |
| 自然科学 | 图景索取 | **图景式理解**——不求计算，但求知道物理法则如何塑造了世界 |
| 人文与社会科学 | 深度投入 | **深度业余者**——哲学与心理学是深入研究的次级域；精神分析是切入口；历史与文学是反复返回的参照系 |
| 应用科学与技艺 | 实用距离 | **概观为主**——不深入，但知概况。唯一例外：**中医学**，因其整体论的身体观与我一年多的实践（阴瑜伽、节律感知、经络体感）相契，详参 |

这个矩阵，是未来与任何大模型对话的**协议**：谈数学切专业直觉，谈精神分析切深度阅读，谈经济学切观念史式概述，而不是模型式推导。

### 4.3 三档标注：喜爱 / 已读 / 未读

标记我所处的状态，共三类：

- **喜爱** —— 塑造过我的，我愿反复回到的
- **已读** —— 我读过了，落下了足迹
- **未读** —— 尚未踏入，但已在星图上照亮归途

> 这不是静态分类，而是**随我生活而变化的快照**——就像镜子里的形象，今天和明天并不完全相同。

## 第五章 足迹图的构成与机制

### 5.1 节点

| 类型 | 形状 | 说明 |
|---|---|---|
| 书（喜爱 / 已读 / 未读） | ● 圆点 | 三态各自的光 |
| 文章 / 书评 / 随笔 | ▲ 三角 | 我的主动产出 |
| 论文 | ■ 方形 | 我正式发表的研究成果 |

点击节点弹出卡片：书名、作者、评分、标为喜爱 / 已读 / 未读。光斑随之生长。

### 5.2 精神质心

取已读与喜爱的书 + 我的文章 + 论文的加权中心（产出方向的权重更高——因为它们指向我**主动**塑造的方向）。质心是光斑的重心，也是"我的精神落脚点"。

### 5.3 盲区推荐

所有未读节点中，距离质心最近者——那才是真正"相见恨晚"的漏网之鱼。

### 5.4 共振度量

分别计算"读子质心"与"写子质心"，用它们的夹角度量：**我的输出与我的输入是否同向**。

## 第六章 设计原则

1. **静态优先，本地优先。** 数据以纯文本（Markdown）/文件形式存在，git 版本化，断网可完整运行。它是一面镜子，不是一座需要维护的服务器。
2. **数据即文本，文本即可读。** 每个条目一个可手工编辑的文件，永远可直接打开修改。
3. **重计算离线做，轻交互在线做。** 嵌入、降维、聚类离线完成；浏览器只渲染与响应。
4. **克制规模，追求清晰。** 不必收录全世界的书，只需要经时间淘洗、且与我有共振潜力的经典——足以形成清晰的精神大陆。
5. **隐私是默认值。** 公开的是星图底图；我的光斑、我的书评、我的文章停留在我自己的浏览器与本地文件中。任何与"我是谁"相关的私人层，绝不进入公开仓库。
6. **艺术品优先于功能。** 这个网站本身就是一件作品——它的每个像素、每句文案、每次过渡，都在为"它是我为自己建造的镜子"这一意图服务。

## 第七章 数字分身：这面镜子的未来读者

这个网站未来将承担一个角色：**作为我的数字分身的基础材料**——当一个大模型需要了解我时，它会加载这份底层数据。

### 7.1 一个模型专用接口

为了让大模型准确读取，网站将预留一个**纯文本出口**：一份可整段粘贴、或通过一个 `profile.md` 接口获取的**精神自画像**。它只陈述事实与姿态，不掺杂展示性的修辞——因为数字分身的使命不是成为通用知识库，而是**准确地反映我如何理解世界**。

### 7.2 对话协议

认知星图的四域姿态矩阵告诉模型：在何处切换深度与方式。这让它学会在我的领域边界处**切换回应方式**——而不是对我滔滔不绝地输出标准百科。

## 第八章 万物相通：终极志向

这是我做这一切的野心，也是凿星图最深的一层命题：

> **我相信，人类所有知识——数学、文学、历史、中医、物理、哲学——在本质上都是相通的。**
> **我学习它们，不是要博闻强识，而是因为我相信：学科之间的墙壁是暂时的，而底层是连通的。**
> **我最终想找到一种语言或方法，能够证明它们相通。**

这三个动作是一体的：
1. **学习** —— 用目录树为所有知识绘制地形，不带偏见地进入每块疆域；
2. **测绘** —— 用凿星图看见学科之间真实的邻接关系，而不是纸面上的分类；
3. **贯通** —— 寻找那一种能同时言说数学之结构与文学之意味的语言。

这面星图，正是为第三种动作而准备的脚手架。每一本书、每一门学科的坐标，都在等待一个可以串起它们的、尚未被人找到的句法。
