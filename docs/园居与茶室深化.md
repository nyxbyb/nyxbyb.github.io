# 迟庭 · 园居与茶室深化

2026-10-21 · 工作方案 · 概念协调

迟庭的中心仍是一个能够独处、工作、泡茶和好好睡觉的家。向外扩展时，画室、运动、电影与游泳各有合适的位置；庭院连接这些日常，也保留没有被指定用途的空处。本篇把官方研究、设计选择与待确认条件分开，不把概念图当作已建成住宅或施工文件。

## 3. 园子由三个层次组成

**内庭是每天观看和走近的地方。** 30㎡内庭继续服务起居与书房，保留通透的小乔木意向、坐处、排水与可清扫的地面。树的最终种类待气候确定，不因为外园增加桂花，就把内庭原有树位强行改成同一种树。绿化不过度遮住窗，也不给开门、检修与清扫留下无法到达的窄缝。

**外园给活动与季节留出范围。** 园路联系主屋、生活翼、坐处与泳池，回家的日常路线不必穿过泳池围界。保留一段可以不做任何事的地面和能停留的树荫；不把所有空处都分配给花坛、雕塑或设备。场地边缘明确画出围合与植物屏界，不用尚未存在的远山替代邻里和地界。

**服务边让花园能够维持。** 园艺工具、室外水点、落叶收集、垃圾暂存与设备检修从服务路线到达；清运和补货不需要穿过茶席。围墙、屏界与植物的高度属于本版空间假设，实际遮阳、风、视线和当地边界条件明确后再调整。

## 4. 桂树适合这里吗

**把桂花列为外园优先候选，而不是现在承诺的一棵树。** [Kew 的 Osmanthus fragrans 资料](https://powo.science.kew.org/taxon/urn%3Alsid%3Aipni.org%3Anames%3A610878-1/general-information)将其描述为主要生于亚热带的常绿灌木或乔木，花香明显。[NC State 园艺资料](https://plants.ces.ncsu.edu/plants/osmanthus-fragrans/)列出的典型尺度约为高3–6m、冠幅3–4.3m，适合全日照或半阴与排水良好的土壤，耐寒分区列为USDA 8a–11b。品种、种植地和养护会改变最终尺度与花期；耐寒分区也不能代替当地的夏季湿热、日照和开花条件评估。

本版的设计选择是：外园留一个可从茶区走近的桂花候选树位；按成熟冠幅留空间，而不是只按购入苗木的大小排图。根域、基础、管线、铺装、排水和修剪到达条件需要一起核对，本文不给未知基础条件套一个统一种植距离。树不贴着茶叶储柜或卧室进风口；花香、落花、落叶和个人感受都要在当地实地体验后决定。

只保留两条有限备选，避免把花园做成植物清单：

| 条件变化 | 候选与依据 | 设计取舍 |
| --- | --- | --- |
| 若是适合其品种的温带环境，优先枝影与季相 | 鸡爪槭 *Acer palmatum*。[NC State](https://plants.ces.ncsu.edu/plants/acer-palmatum/)建议斑驳遮阴、均匀湿润而排水良好的土壤，并注意干风、强晒与干旱造成的叶灼。 | 用叶色、枝影与落叶变化替代对花香的期待；不把它默认种入全年湿热或暴晒的地点。 |
| 若是真正的热带或季风环境，希望较小尺度的香花植物 | 九里香 *Murraya paniculata*。[NParks](https://www.nparks.gov.sg/florafaunaweb/flora/2/2/2239)记录其香花、热带及亚热带适应性，栽培常维持约2.5–3.5m，亦可能长得更高；造型绿篱会增加维护。 | 作为局部灌木或小树候选，不把它修成遍布全园的整形墙；确认本地适生与可控尺度后再选。 |

城市未定之前，最有价值的是保留树能生长的地方、好用的窗景和可维护的种植地，而非先锁定一份全年不变的效果图。

## 5. 茶、水、听音与香气

### 茶席需要一个安静的后台

本版仍采用桌椅茶席，独坐舒适，也能招待两三位朋友，不要求席地而坐或复刻某一茶道流派。表千家的[水屋教材](https://www.omotesenke.jp/info/publication/dvd/09.html)把备茶和收拾列为茶事的基本部分；迟庭借鉴的是这种对准备和归整的重视，不把日本茶道程序强加给功夫茶的日常。

完整顺序是：取茶与杯 → 补水、烧水 → 坐下冲泡与慢饮 → 倒废水与茶渣 → 清洗 → 晾干 → 归柜。茶桌上有干泡茶盘、小保温壶和废水盂，让泡茶本身也成为坐着完成的过程；茶柜承担定点烧水、备用冲泡与清洗，不把期待中的独处变成站在柜前的连续作业。

本版采用2.55 × 0.60m、台高0.90m的茶柜，电热壶在柜上补水与烧水，不将装满热水的电壶搬过主通路；小保温壶用于短距补水，日用杯壶与托盘易取，备用器物收起。茶湾内约0.55m是局部人员服务间隔，不是电壶到桌的全部空间距离，也不能称作全屋主通道或无障碍通路；全屋路径改经回廊协调。清洗与废水处理、供电和检修依同模型点位深化，湿杯不直接放进密闭干茶柜。

干茶与香气物件分柜。[一保堂的储茶说明](https://ippodotea.com/blogs/frequently-asked-questions/how-should-i-store-my-tea)要求避开日光、高温、湿气与强气味；具体包装依茶叶种类及生产者说明处理，不为所有茶统一设计恒温恒湿设备。

### 先有主听位，再选设备

主听位与茶席共享一室，但不要求每张茶椅都成为立体声最佳位置。[Genelec 官方布置指南](https://www.genelec.com/monitor-placement)强调左右对称、音箱朝向听者与约60°的立体声关系，房间和摆位同样影响听到的声音。迟庭将这些作为试听起点，非某个音箱型号的通用安装尺寸。

本版将音箱中心试摆为(1.79, 8.55m)与(3.81, 8.55m)，沙发主听位为(2.80, 6.80m)：左右基线约2.02m、听距约2.02m、夹角约60°。这是同模型的几何起点，尚未完成型号、耳高、离墙距离与房间低频的核验。后续可用临时支架在地面标出几个位置，实际坐下试听，再决定线缆、插座和固定柜体。窗帘、地毯与软坐支持日常使用；它们不能代替门墙隔声，也不把调音软件视为修正一切位置问题的办法。夜间先有安静听音或耳机的选择，不必为了多声道立即改变主屋。

### 香气可以出现，也可以消失

精油收在独立小抽屉，扩香设备使用时取出，结束后可关闭和收起。无印良品的[精油保存说明](https://faq.muji.com/エッセンシャルオイルの保存方法を教えてください-65cc5db10182170025c1f65b)建议使用原有遮光瓶、密闭保存在通风冷暗处，避开火源及浴室等高湿环境。此处据此安排收纳，不作疗效承诺。

设计上将闻茶与扩香分时：认真品茶时先关闭扩香，想听音乐或独坐时再选择气味。这是保护个人选择和茶香层次的空间判断，并不是要求居住者遵守固定仪式。茶、水、电、书与香各有归位点，仪式感才不依赖每晚重新整理一遍房间。

泳池采用**独立的四边隔离围界与自闭、自锁门**，将水域和住宅及普通庭院活动分开，不能把地块外墙当作泳池隔离。普通园路和回家路线位于围界之外。这一取舍参考[CDC泳池隔离建议](https://www.cdc.gov/drowning/prevention/index.html)与[Pool Safely屏障资料](https://www.poolsafely.gov/2017/05/08/summer-safety-barrier-checklist-for-pool-and-spa-owners/)；实际高度、门锁、构造与出入口仍按所在地及专业设计核实。

## 7. 还需要什么：少而必要的配套

只增加三组会直接影响使用的后台，而不继续扩张兴趣房间：

1. **运动后的干湿过渡**：生活翼12㎡服务区统筹淋浴、换衣位置、干净毛巾与湿衣暂存；有私密遮挡的室外冲洗点是否增加，随气候与使用频率决定。湿脚回主屋的路线不能穿过影音设备或茶席。
2. **可检修的设备与储物**：泳池处理设备、运动器材、清洁用品与园艺工具有合适的噪声、通风和检修条件；空间是否足够，按实际设备尺寸核对。化学用品不与毛巾、茶或创作材料混放。
3. **园子的水与维护入口**：浇灌、清洗、排水、落叶处理和设备更换有清楚路线。工具可以归位，维护者可以到达，园景才能保持安静而不是不断制造家务。

分期的理由是使用经验有价值：先完成每日会坐下的茶席、主屋与基本庭院；再用真实运动和观影习惯决定生活翼的设备；泳池最后与水处理、隔离、维护投入一并落定。图上可以保留完整远景，每一期也应能独立成立，不靠下一期才能解决本期的日常。

下一轮优先确认真实城市与基地、主听位和音箱类型、创作媒介、运动器材、游泳用途及可投入的维护时间。花香、声音、树荫和水的想象由此获得可以逐步检验的尺度。
