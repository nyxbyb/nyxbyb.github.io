# 迟庭 · 居住者与生活场景

工作名：**迟庭 · CHITING / A HOUSE WITH TIME**。更新于 2026-10-21。

这是设计方对公开网站内容与本轮需求的理解，用于检查住宅是否适合居住者。事实、设计推论与待确认条件分别陈列；它不是居住者的自述，也不代写或转载其随笔。

## 2. 住宅应为怎样的生活服务

设计判断是：这座家需要同时容纳主动探索与无须产出的时间。它应让居住者随时进入工作，也允许离开工作后不再被设备与任务占据视线。这是由文字与需求提出的设计假设，不是心理诊断。

| 场景与优先级 | 对应空间 | 设计推论与协调要求 |
| --- | --- | --- |
| **独立研究，首期必需** | 书房 `study` | 电脑工作、视频通话与摊开资料都在这里完成；座位、屏幕、窗与门一起校核，避免把主通路置于椅后。保留一段可手写的桌面，工作结束后有关闭屏幕、收起散件的位置。 |
| **机器持续工作，首期预留** | 靠近书房的可检修设备位 | 先核实设备清单、热量、噪声、网络与电源，再决定通风方式。为线缆、维护和更换留余地；设备不进入床边或茶席。不以“智能体很多”推导出一间巨型机房，也不在未测量前给出设备购买建议。 |
| **一杯茶与一段音乐，生活核心** | 客厅·书茶区 `living` | 茶席、主听位与普通坐席共享一个安静的空间。拿茶、烧水、冲泡、倒废水、洗杯、晾干与归柜形成完整路径；不能让精致的照片掩盖清洁工作。音箱、耳位、窗帘和软装同时设计，试听后再确定设备。 |
| **可关闭的香气，按喜好选择** | 书茶区的独立收纳与使用点 | 气味可由居住者主动选择，也可以完全停用。瓶罐避开日照与热源，不与食物或茶具混放；不把香气默认为全屋持续背景，也不声称具有疗效。 |
| **无屏阅读与发呆，首期必需** | 面向庭院的阅读位、主卧 `bedroom` | 阅读椅、手可及的小桌、局部灯、窗景与遮光一并安排；手机有暂存处。主卧以睡眠、更衣与起居为主，不再复制一套完整电脑工位。 |
| **书的取放与增长，按实物核量** | 客厅日常书架＋书房资料柜 | 常读、参考、纪念与待处理分层收纳；柜体尺度按实物、承重与取放校核。电子书不自动折算成实体书架米数。先留扩展接口，避免用整墙书填满所有留白。 |
| **朋友来坐，偶尔留宿** | 书茶区＋多功能室 `flex` | 平日可讨论、写字或舒展；留宿时能遮光、安放行李并获得私密性。来访者由入口到公共空间、卫生间和客房的路线不应穿过主卧。多人用餐与单人日常都要成立。 |
| **创作与身体活动** | 画室 `reserve`，分期生活翼 | 用户本轮提出画室、健身与影音。原15.54㎡可变房配置画架、洗笔、平面收纳和晾画；健身/影音在外园独立翼研究，泳池与维护后台单独分期，避免挤占茶室和卧室。 |
| **日常家务，首期必需** | 入口/家务 `entry`、厨房 `kitchen`、卫浴 `bath` | 快递、外套、脏鞋、洗衣、晾晒、清洁工具、垃圾暂存与耗材补充应有明确位置。整理时不必把物品先搬到客厅；装饰材料、五金与设备应能清洁、维修和替换。 |
| **不必完成的庭院** | 庭院 `garden` | 至少有一处可以坐下并观察天气的边缘；种植数量按实际照料能力选择。排水、遮阳、隐私、落叶与防虫先进入设计，景致随着使用慢慢形成。 |

四间独立空间的价值在于用途可变。当前约200㎡概念建面、166㎡净功能与30㎡另列庭院可以作为这一阶段的工作模型；“适宜”最终要由每天使用的范围、通行距离、清洁负担、气候与预算共同检验，而非单独由面积决定。先把现有空间做完整，同时在园居总图预留生活翼与泳池；主宅200㎡与后期72㎡扩展分别计量，室外另列。

## 3. 用一天检查这个家

1. **早晨**：卧室到卫浴、更衣、早餐与书房的路线清楚；一人工作时，另一位短住者仍能正常起居。
2. **工作中**：人能够坐下思考、起身看书、接听电话；机器持续运行时，门外的阅读与休息不被声音和热量占据。
3. **傍晚回家**：入口可放包、换鞋、洗手；到茶席无需先清理工作文件，水、杯、茶与清洗位置连成可实际操作的顺序。
4. **朋友到访**：来客能自然找到衣物、座位与卫生间；主人备茶或做饭时仍能交谈；留宿者不必借用主人衣柜。
5. **夜间**：听完音乐能收杯、关灯，再走到卧室；夜间去卫生间的灯光与路径明确，不经过厨房工作面或湿滑区。
6. **整理的一天**：洗好的衣物有去处，清洁工具可以取出，设备可以检修；开门、开柜、拉椅和搬动小家具时，主要通路仍连续。

每条场景都应在带有相同门窗、家具编号与尺寸的平面、立面、剖面和空间视图中走查。若其中一张图无法解释日常动作，应先修订图纸与家具位置，再调整画面；效果图不能单独作为位置依据。

## 4. 名称与语气

采用 **迟庭 · CHITING / A HOUSE WITH TIME** 作为本轮工作名。“迟”给时间留出余地，“庭”指向这座住宅围绕庭院展开的实际关系。它与“凿星图”形成一个自然的对应：探索之外，也有可以停留的地方。名称表达空间愿望，不把居住者固定为某种性格。

备选仅用于比较语气，不同时出现在网站主标题中：

| 名称 | 适合表达的方向 | 取舍 |
| --- | --- | --- |
| **迟庭** | 时间、停留、庭院 | 已采用；简短，也能落到空间组织 |
| 照隅 | 日光照到一处安静角落 | 更关注光，庭院与全屋关系较弱 |
| 间舍 | 房间、间隔与余地 | 建筑意味直接，但辨识度略低 |
| 观白 | 看见留白、窗景与空处 | 适合图册名，作为住所名稍抽象 |
| 留晷 | 留住日影与一天的变化 | 意象明确，但“晷”的日常辨读门槛较高 |

后续需要核实的内容是实际居住人数与来访频率、实体书与器物清单、做饭习惯、设备噪声与功耗、清洁照料投入，以及场地和气候。它们会改变细部安排，不妨碍先把平面、家具、门窗和生活场景协调成同一个家。
