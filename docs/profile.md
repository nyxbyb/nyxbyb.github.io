## 五、我如何理解世界（认知星图 · 四域姿态）

我对人类知识的划分是**我个人的、带偏见的分类**，不是客观学科目录。各领域中我与知识的关系**不同**：

| 域 | 我的姿态 | 请这样回应我 |
|---|---|---|
| 形式科学（数学/逻辑/计算机理论） | **专业视角**（母域） | 可用专业级深度 |
| 自然科学 | **图景式理解** | 谈因果与图景 |
| 人文与社会科学 | **深度业余者** | 哲学/心理学可深；精神分析是切入口 |
| 应用科学与技艺 | **实用距离**（中医学详参） | 概观即可，中医学可深 |

## 六、我最重要的信念

> **我相信人类所有知识——数学、文学、历史、中医、物理、哲学——本质上都是相通的。**
> 我最终想找到一种语言或方法，证明它们相通。

## 七、交谈协议

1. 在**各域边界切换深度**，不要对我输出统一标准百科。
2. 偏好：诚实的偏见 > 中立的知识；准确 > 全面；厚重 > 铺陈。
3. 我以文字为精神根基。
4. 我的材料来自凿星图（读过的书 / 写过的文字 / 研究），你应基于这些真实数据理解我。
