# 凿星图 · 编辑入口指南

> 经常要改的内容，只需碰一个文件。这是"改哪里、怎么改"的总索引。
> 全部编辑后，只用在终端跑三行命令就能上线（见文末"如何上线"）。

---

## 一、星域目录树（四域 → 次级 → 细目 → 叶子）

**文件**：`web/public/tree.json`

- 每个域（形式科学 / 自然科学 / 人文社科 / 应用科学）是 `{ "id","zh","en","children":[ … ] }`
- 有 `children` 的节点 = 目录（可再点进去）；没有 `children` 的节点 = **叶子页**（学习笔记）
- 想加一门学科 → 在某层 `children` 里加一个 `{ "id":"xx","zh":"学科名","en":"English" }`
- `posture` 字段（如"专业视角 · 我的母域"）会显示在节点右下角

> 这是目录的唯一真源。改这个文件，星域下钻导航自动跟着变。

## 二、首页名片

**文件**：`caelum.html` → 顶部 `第 1 屏：序` 那块

- 中文名：`.name-cn` → `保昱冰`
- 英文名：`.name-en` → `YUBING BAO`
- 字：`.name-zi` → `字 坚心 —— 取自《周易》…`
- 英文版文字在 `<script>` 里的 `I18N` 词典（`introZi` 等键）

## 三、拓星（研究方向 + 代表作）

**文件**：`caelum.html` → `第 4 屏：拓星` 那块（文件里有 ✏️ 标记注释）

- 研究方向：三个 `<span>` 标签文本
- 代表作：每个 `<a class="frontier-item">` = 一篇论文，`fi-meta` 是作者与 venue
- 加一篇 → 复制一个 `frontier-item` 块改内容；删一篇 → 删掉整个块
- 完整学术履历链接 → `frontier-more` 的 `href`

## 四、理念页（散落的句子）

**文件**：`caelum.html` → `第 5 屏：理念` 那块（有 ✏️ 标记注释）

- 每句是一个 `<p class="vs vs-1">…</p>`，改 `…` 里的文字即可
- 想增句 → 复制一个 `.vs-*` 并在 CSS 里加一个 `vs-11` 的坐标（`top`/`left`）
- 想调整某句位置 → 编辑 CSS 里 `.vs-3 { right:8vw; top:26%; }` 这类坐标
- 英文版在 `I18N` 词典（`v1`..`v10` 键）

## 五、跋 / 手册链接

**文件**：`caelum.html` → `第 6 屏：跋`

- 三个链接（空间手册 / 时间手册 / GitHub）在 `.about-links`

## 六、星图数据（书单 / 坐标）

- 书单源：`scripts/crawl_all.py` 抓豆瓣（1028 本） → `corpus/books_raw.json`
- 嵌入+降维：`scripts/embed_map.py` → `web/public/data/graph.json`
- 想加书：改/扩 `corpus/books_raw.json` 后重跑 `embed_map.py`

---

## 如何上线（改完跑这三行）

```bash
cd ~/Desktop/Caelum
cp caelum.html web/index.html   # 同步最新主页
git add -A && git commit -m "更新" && git push
```

push 后 GitHub 会自动构建并发布到 `https://nyxbyb.github.io`（约 1 分钟）。

> 如果改的是 `tree.json` / `graph.json`，需要先跑对应脚本再走上面流程。
> 你的**已读标记、书评、学习笔记**都存在浏览器里，发布不会清掉，也不会上传——它们永远只属于你和这台浏览器。
