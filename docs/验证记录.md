## 修改前线上证据

原站 `https://nyxbyb.github.io/web/` 在桌面浏览器加载个人介绍和研究链接，但控制台复现 `immIdleLoop` 访问 null.classList、`openLeafPage` 访问 undefined.zh 两个错误；四域目录未显示，文章区域停留在占位文案。独立 HTTP 检查发现 canonical 数据地址 404，数据实际留在源码目录的 public 子目录。详情及 URL 状态见《工程审计与房间方案》。
