# 迟庭 · 住宅设计交付体系

研究日期：2026-10-20。本文是后续住宅图册的交付目录与审查依据，不表示目录中的每项已经完成。现行面积依据见《未来住宅设计简报》：约 200㎡ 概念建面，166㎡ 净功能与 34㎡ 构造设备预留，30㎡ 庭院另列，四间可以独立关门的空间。

## 先把一个家讲清楚

专业住宅设计的成果，是一组能互相核对的决策：谁在这里生活，如何到达每个地方，物件放在哪里，光与空气如何进入，怎样清洁、维修和适应未来。照片、平面、清单与文字共同描述这一套决策。

本住宅接下来采用统一的空间资料作为门窗、家具、视点与动线的依据。每一张空间图都应标注所属房间、观看方向和图版版本。改变门、窗或柜体后，要检查平面、房间图、房间卡和清单是否同步。这样形成的图册，才适合作为未来与建筑师、室内设计师交流的底稿。

## 官方资料中能核对到什么

下表只概括一手资料可以支持的内容；右栏是 Caelum 的原创取舍，不是这些事务所为本项目提出的建议，也不是服务合同中的统一交付标准。

| 官方一手资料 | 可以核对的工作内容 | 本住宅可采纳的方式 |
|---|---|---|
| [Snøhetta · Interior Architecture](https://www.snohetta.com/disciplines/interior) | 描述空间使用情境与体验序列；空间规划、细部、声学、材料知识与相应采购也进入室内设计工作。 | 用一天中的生活片段检验方案；给房间补充动线、声学与家务说明，明确物件的使用和归位位置。 |
| [Snøhetta · Product Design](https://www.snohetta.com/disciplines/product) | 服务包括研究、概念、设计细化、色彩/材料/表面处理，以及生产和技术发展。 | 建立少量连续的材料编号，结合家具、灯具、柜体与门把手查看，避免每个房间各用一套装饰语言。 |
| [Norm Architects · About](https://normcph.com/about/) 与 [Bespoke](https://normcph.com/project_category/bespoke/) | 官方工作涵盖建筑、室内、产品及感官体验；定制项目目录有书架、柜体、厨房、座椅与灯具。 | 将书墙、茶柜、长书桌与照明当作空间的组成部分；按真实用途深化，再判断需要定制还是选用成品。 |
| [John Pawson · Kitchen System II](https://www.johnpawson.com/works/kitchen-system-1?object=true) 与 [Door Handle](https://www.johnpawson.com/works/door-handle-1?object=true) | 厨房系统把台面、座位、柜体与搁架一起组织；门窗五金项目明确尺寸与表面选项。 | 同时研究做饭、坐下、收纳与通行；细部表需写清尺寸、材质和维护方式，不能只有一张产品照片。 |

这些来源说明，完整设计可以延伸至空间中的日常物件及使用方式。它们不要求个人住宅照搬商业项目的规模，也不意味着应当购买对应品牌。

## 按阶段组织成果

[RIBA Plan of Work 2020 官方总表](https://www.riba.org/media/sszn5kkt/2020ribaplanofworktemplatepdf.pdf)将工作分为需求与准备、概念、空间协调、技术设计、建造、交付与使用等阶段。概念包含简报、初步规格与成本计划；空间协调需要建筑和工程信息协同；技术阶段形成建造所需信息。该框架是工作组织参考，具体服务与责任仍由项目约定。

以下是为本住宅建议的阶段目录，不将英国流程或审批内容直接套用为本地要求。

| 阶段 | 建议形成的成果 | 需要解决的问题 |
|---|---|---|
| 生活需求与概念研究 | 生活简报、面积表、空间关系、带家具平面、概念剖面、材料方向、使用情境、待确认清单。 | 房子容纳什么生活；空间数量和尺度是否合适；主要矛盾是什么。 |
| 空间深化与协调 | 统一门窗家具表、逐室立面与剖面、厨房和卫浴放大图、灯光/设备策略、收纳与维护清单、备选方案、更新的成本依据。 | 每件东西是否放得下；开启和通行是否互相干扰；各专业是否占用了同一位置。 |
| 技术设计与施工配合 | 经专业设计协调的施工图、节点与规格、结构和机电信息、选型与供应商资料、实物样板、工程量与采购文件、现场答疑。 | 如何制造、安装、验收与维护；具体责任、费用和风险如何落实。 |
| 交付与居住反馈 | 设备调试、竣工资料、保修与维护手册、缺陷记录、入住反馈与调整。 | 实际住起来是否舒适；设备怎样运行；后续如何维修、替换和改造。 |

网页本轮适合推进第一阶段，并形成第二阶段的概念研究底稿。尚无真实地块、测绘、预算、结构和机电条件时，不把图版称为施工图、报建文件或已通过性能验证的方案。

## 建议的全屋图册目录

| 编号 | 图册或资料 | 本住宅应呈现的内容与核对方式 |
|---|---|---|
| 01 | 生活简报与设计命题 | 阅读研究、计算机项目、独处、茶与音乐、来客、家务、未来变化；写明事实、设计推断和待确认事项。 |
| 02 | 全屋面积与家具平面 | 净面积与构造预留分别标示；家具使用实际尺寸占位；门扇、柜门及电器开启范围进入核对。 |
| 03 | 动线与生活情境 | 归家、烹饪上菜、入睡、访客、洗晒清洁分别追踪；每条路径从真实入口到真实目标。 |
| 04 | 逐室空间图与视点索引 | 房间编号、视点、朝向和可见门窗相互对应；几何可核对的二维图作为位置依据，氛围影像用于材料和光感研究。 |
| 05 | 立面、剖面与空间尺度 | 至少研究公共区/庭院的连续剖面，以及书墙、茶柜、书桌、床柜与餐厨关键立面；展示高度、开口和人体关系。 |
| 06 | 门窗与边界表 | 开口编号、位置、宽高、开启方向、遮阳与窗帘、视线和隐私；图像中出现的门窗能追溯到表。 |
| 07 | 家具、固定柜与物件表 | 家具编号、尺寸、落位、可移动/固定、现有/拟购、维护方式；成品与定制均保留替换空间。 |
| 08 | 材料与触感册 | 材料编号、应用区域、表面与拼接方向、清洁修补、实物样板待核对项；湿区、干区分别考虑。 |
| 09 | 照明与环境策略 | 阅读/工作/做饭/清洁/晚间的不同需要；窗、遮阳和灯具位置共同查看。示意不冒称照度、日照或热工计算。 |
| 10 | 收纳、家务与设备 | 书、茶具、杯盘、床品、行李、清洁工具、洗晒、垃圾与耗材；设备的噪声、散热、检修和替换路径。 |
| 11 | 庭院与室内外过渡 | 树、坐处、遮蔽、地面、雨水与维护；在基地气候明确前，植物品种与构造保持待选。 |
| 12 | 选型、成本与变更档案 | 需要/可延后/可替换的优先级；报价来源、日期、数量与范围明确后再汇总费用；保留版本和决定理由。 |

实物阶段还可制作材料拼板、柜体和节点样件、灯光试装，以及用胶带在地面做关键家具的 1:1 放样。本网站可以记录样板与验证结果，不能从屏幕图片确认真实触感、反光、颜色或安装质量。

## 房间卡应怎样写

每间房用一张可核对的房间卡连接图像与图纸。建议字段如下：

- 房间编号、名称、平面位置、净尺寸和面积口径。
- 相邻房间、门窗编号、图像视点与观看方向。
- 家具及柜体编号、占位尺寸、开启范围和主要通路。
- 可完成的生活活动，以及需要安静、遮光、通风或防水的时刻。
- 材料、照明和设备索引；书、衣物、茶具等物件归位位置。
- 清洁、维修与未来调整方式；尚未确定的选型和尺寸。
- 版本日期与本次修改原因，所影响的其他图版。

同一房间的轴测、平面和立面从同一组几何资料生成，可以直接核对位置。生成式写实影像即使依据平面制作，也需要逐项审阅可见开口和家具；发现偏差时应改图或明确标出，不能让影像自行改变方案。看不见的门窗不等于不存在，无法从单个视点判断的项目仍需回到图纸核对。

## 从用户随笔得到的设计任务

以下是根据本次用户提供的文字所作的空间推断，仍可以随着实际生活修订。文章不是心理诊断材料，设计不假设一个人的兴趣和家庭结构永远不变。

| 随笔中的生活事实 | 本住宅的设计回应 | 应在哪份成果中体现 |
|---|---|---|
| 并行计算机项目，等待智能体结果时继续开展其他工作。 | 书房设置稳定的工作面和设备位；把线缆、散热与可能的噪声纳入设计，设备容量依真实清单确定。 | 书房房间卡、家具与设备表、供电/网络需求说明。 |
| 写作、研究、计算机、中医与精神分析等阅读并存。 | 藏书分为手边在读、公共阅读与归档；纸面写作有可放下电脑的位置，不按学科各造一间房。 | 藏书与书墙立面、阅读照明、收纳表。 |
| 希望傍晚泡茶、听音乐、体验气味，并享受独处。 | 茶席与听音座位共享公共区的一角；设置茶具归位与备水路线，音乐设备的位置和线路与家具一起确定。气味装置保持可移动、可关闭，避免固定成全屋背景。 | 茶席局部平面、公共区立面、动线和物件表。 |
| 同时向往简洁与有仪式感的物件。 | 以闭合收纳支持少量日常展示；先规定常用物件放在哪里，再增加柜体和摆件。 | 收纳容量表、柜体立面、维护清单。 |
| 不想时时追求效率，也会持续生出新项目。 | 保留离屏座位、无设备床边和一块不预先塞满的多用空间；进入睡眠空间时能把工作物件留在外面。 | 安静动线、主卧房间卡、未来预留房的两种布置。 |
| 希望以后可能真正建造，又享受今天设计它的过程。 | 维持 180–220㎡ 的可讨论住宅模型；按可迁移的局部积累参考，真实基地出现后再调整整体形式。 | 设计简报、优先级、待确认清单和版本档案。 |

此刻最值得增加的是可关门的工作空间、可离屏的停留处、完成家务的后台和应对生活变化的余地。每增加一间专用房，都要回答使用频率、维护负担和能否共享。房屋尺度以这些活动能否从容发生为依据，面积扩张本身不作为设计目标。

## 后续可以交给真实项目团队的资料

保留用户确认过的生活简报、空间关系、喜欢与不喜欢的材料、标注过的问题、带日期的版本、物件与设备清单及预算优先级。真实设计启动时，补充所在地、地块/现状测绘、朝向、周边环境、常住与短住需求、预算、结构和设备条件，再由相应专业继续核实。

这套资料帮助下一位设计者理解一个具体的人怎样生活，也让用户能够看见每次改动为什么发生。图册的价值来自持续一致的决策和可追溯的验证。
