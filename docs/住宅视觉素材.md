## 来源与使用

五张图均为内置 `image_gen.imagegen` 生成的原创概念素材，使用 `imagegen` 技能的默认内置模式；没有调用 CLI、外部 API 或第三方项目图片，也没有宣称由某位建筑师设计。图像不复制指定建筑作品，统一通过木作比例、自然光、收纳整合、材料触感与留白建立风格。

## 逐图检查与可用范围

已用 `view_image` 检查全部最终 JPEG：书房具有显示器、键鼠、桌面留白与支撑型工作椅；卧室有普通高度床架和封闭衣柜；厨餐有 L 形台面、排烟罩、冰箱柜位与四人餐桌；卫浴可辨淋浴玻璃、排水槽、干区洗衣柜和排气口；多功能室有开敞地面、储物壁、折叠床柜立面与庭院光线。

这些是氛围、用材、家具与生活场景的概念图，不是对网站平面方案的精确透视重建。提示词中的房间面积用于控制画面尺度，不能用像素或图中比例反推真实尺寸。平面尺寸、机电管线、衣柜与折叠床结构、柜门开启、玻璃规格、地面防滑、防水坡度和电器散热应在选址和实测后继续深化。卫浴图展示组合湿区与洗衣的一种关系；实施时可把洗衣移至相邻独立家务区。

与网页对应的设计原则是：橡木尽量用于干区木作；湿区使用有防滑要求的耐水表面；电脑桌的采光和屏幕眩光需要随实际朝向重新确认；保留通道和可变空间，避免仅为视觉填满家具。图片中的窗外树林代表景观意向，未确认真实场地景观。
