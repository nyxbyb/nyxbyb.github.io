## 为什么需要再做一轮

第二版 living 与 garden 对同一段 W03 庭院立面的表达存在偏差：室内的窗接近地面，室外的窗下灰泥带显得明显高于模型中的 150mm；中间墙柱与窗头、屋檐没有统一的几何来源。庭院的植物、反射和室内家具虽然经过局部修正，也不能替代内外两面立面的逐项检查。

本轮以冻结后的空间模型、固定视点几何图和两面立面为依据。旧庭院照片只可以帮助确认色材，不作为建筑几何参照。茶席采用独立机位，完整展示茶桌、座位与备水归位；原预留室随用户用途深化为画室，需要对应画架、晾画、平面收纳与洗笔台的真实摆位。

## 已确认的几何与风格约束

- W03 厚度 0.24m；内庭长窗 V06 位于 x=0.45–4.05m，窗台 0.15m、窗头 2.50m。
- 推拉门 D09 位于 x=4.20–5.40m，门头 2.50m；V06 与 D09 之间保留 0.15m 实墙柱。窗与门不能互换或合并为无墙玻璃幕。
- 室内研究顶高 2.70m。窗头、顶面、屋檐与墙体进深由最终模型共同约束，不由影像临时增减。
- 沿用浅自然橡木、暖白细灰泥、米色亚麻、少量浅灰石质操作面。四张采用相容的柔和日光、材质与家具语言。
- 家具、开口、檐口和相机位置在生成前冻结；看不见的内容回到图纸核对，不把全部物件强行拉进同一张照片。

## 工具与保存方式

采用内置 `image_gen__imagegen`，由模型几何参考进行 `sketch-to-render`；有明确局部偏差时才进行 `precise-object-edit`。不采用 CLI、API Key 或外部建筑照片。每次输入前均查看参考图；原始 PNG 保存至工作区，再以系统 `sips` 转为网页 JPEG，不使用脚本绘制或替代生成影像。

最终约定文件为 `living.{png,jpg}`、`garden.{png,jpg}`、`tea.{png,jpg}`、`tea-evening.{png,jpg}` 和 `reserve.{png,jpg}`；只有明确选用的输出进入这些文件。参考快照存于同目录 `references/`；未采用的工具输出保留在内置工具原始目录，理由写入本记录。
